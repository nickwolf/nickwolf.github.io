Privacy policy

Drive-Claude-Connector. Last updated 17 November 2026.

Drive-Claude-Connector is a personal tool used only by its developer, Nicolas Wolf. It is not available to the public.

What it accesses

When I run it, it reads and writes Google Drive files and Google Docs in my own Google account, using the access I grant when I sign in. It does nothing on its own or on a schedule.

What it stores

It keeps one sign-in token, on my own computer, so I don't have to sign in every time. It doesn't collect, store, sell, or share any other data, and it sends nothing anywhere except to Google's APIs.

When I ask Claude to work on a document, Claude reads that document's content as part of the task, under my own Anthropic account.

Google user data

Drive-Claude-Connector's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data from Google APIs is never used for advertising.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
