Drive-Claude-Connector

A personal tool by Nicolas Wolf

Drive-Claude-Connector lets Claude Code, Anthropic's coding assistant, create and update Google Docs and Google Drive files in my own Google account. It's a small script that runs on my computer when I ask it to.

It isn't offered to anyone else, and there's nothing to sign up for. If you've reached this page from a Google sign-in screen, that screen was meant for me.
